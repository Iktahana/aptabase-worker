# Security reporting

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/Iktahana/aptabase-worker/security/advisories/new). Repository maintainers should enable this feature in GitHub Settings → Code security before accepting public traffic. If private reporting is unavailable, open an issue requesting a private contact without including exploit details, credentials, or event payloads.

For forks, replace the reporting link with your own private channel. Rotate compromised Cloudflare tokens immediately. SDK App-Keys are client-visible identifiers and are not authentication credentials, but may be rotated using multiple keys for the same app ID.
